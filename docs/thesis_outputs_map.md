# Thesis Outputs Map

## Purpose

This page maps the main thesis notebooks and figure-producing workflows to the
parfiles and estimator keys they rely on. It is intended as an operational
guide for rerunning or checking the analysis.

## Main Notebooks

### `THESIS/PT_results.ipynb`

Primary role:

- compares `C_L^{\phi T}` across lensed and delensed scenarios

Main scenario set used in the notebook:

- baseline lensed with `p`
- delensed with input `kappa` using `parfile_delensed.py` with `p`
- internally delensed with MV-QEST using `parfile_delensed_qest.py` with `p`
- internally delensed with Pol-QEST using `parfile_delensed_PolQEST.py` with `ptt`

This pattern is used for both:

- `parfiles/noNoise/*`
- `parfiles/Noise/*`

### `THESIS/PP_results.ipynb`

Primary role:

- compares `C_L^{\phi\phi}` and related lensing-amplitude style summaries across
  the same scenario families

Main scenario set used in the notebook:

- baseline lensed with `p`
- delensed with input `kappa` using `parfile_delensed.py` with `p`
- internally delensed with MV-QEST using `parfile_delensed_qest.py` with `p`
- internally delensed with Pol-QEST using `parfile_delensed_PolQEST.py` with `ptt`

Additional usage:

- some baseline polarization-QE comparisons use `p_p`

### `THESIS/Carron_2017.ipynb`

Primary role:

- comparison / validation style notebook

Important note:

- some stored output cells in this notebook reference older Windows-style paths
  such as `/mnt/d/THESIS/...`
- treat those as historical execution traces, not as the current runtime
  configuration

### `THESIS/Amplitude.ipynb`

Primary role:

- amplitude-oriented summary plots after the main spectra have been generated

## Scenario Table

The core thesis comparison matrix is:

| Scenario label | Parfile | Estimator |
| --- | --- | --- |
| MV: lensed | `parfile.py` | `p` |
| MV: delensed with input `kappa` | `parfile_delensed.py` | `p` |
| MV: internally delensed with MV-QEST | `parfile_delensed_qest.py` | `p` |
| TT / Pol-QEST internally delensed | `parfile_delensed_PolQEST.py` | `ptt` |

This matrix appears in both:

- noisy analysis branch
- noiseless analysis branch

## Driver Relationship

`run_parfiles.py` is intended to precompute the scenario set used by the main
thesis notebooks. The current driver includes:

- noiseless baseline lensed
- noiseless baseline polarization QE
- noiseless input-kappa delensed
- noiseless internally delensed MV-QEST
- noiseless internally delensed Pol-QEST
- noisy baseline lensed
- noisy baseline polarization QE
- noisy input-kappa delensed
- noisy internally delensed MV-QEST
- noisy internally delensed Pol-QEST

## Practical Use

If a thesis plot looks inconsistent, check in this order:

1. the parfile used for that scenario
2. the estimator key used for that notebook cell
3. whether the required cached products were generated by `run_parfiles.py`
4. whether the runtime paths `PLENS`, `INPUT`, `PARAMS`, and `KFIELD` point to
   the expected cluster directories
